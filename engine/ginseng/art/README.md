# Supplied Braille portrait

`cyberpunk.txt` is the sole available artwork. It matches the user’s supplied portrait,
including the original padding. The rendered view removes only empty outer margins.
Every remaining glyph is unchanged; small viewports scroll instead of shrinking it.

The inspector, boot screen and **Ctrl+W → Artwork** all show this portrait.
There is no artwork picker, cycling shortcut or alternate-art command.
