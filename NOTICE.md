# Source and attribution

Ginseng TUI is a standalone terminal distribution extracted from
[Ginseng](https://github.com/nunera/ginseng), including the working-tree TUI
customizations maintained by Zachary Stubbs.

Source baseline: `1d306881fc94e1dbfd4ba153a7fc885ee518c842`. The extraction includes local changes
to the soft club interface and its tests, so it is not an exact copy of that commit.
Original contributors retain credit for their work.

The original source tree did not contain a repository license. This extraction
does not assign a new license to upstream code or to the supplied artwork.
The screenshot and cyberpunk portrait were supplied for this interface.
